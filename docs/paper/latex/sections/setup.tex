\section{Experimental Setup}\label{sec:setup}

\paragraph{Items.} Candidate realising papers were the 300 most recent arXiv submissions (cs.CL, cs.LG, cs.IR, cs.AI) matching ``we propose'' in the abstract, submitted 7--10 September 2026, all indexed by Semantic Scholar. From these, an LLM assistant (Claude) working for the author selected \CandidatesChosen{} method papers in NLP, IR and ML with an idea statable without naming the paper (not benchmarks, surveys, datasets or position papers), for topical diversity. After the exclusion rules of \S\ref{sec:benchmark}, \PilotItems{} items remained (Appendix~\ref{app:items}). All realising papers post-date the agent model's training data (Nemotron~3 Super: released 11 March 2026, post-training data cutoff February 2026), and in the closed-book probe the agent model answered \textsc{none} for every item.

\paragraph{Model and harness.} The agent is NVIDIA Nemotron~3 Super (\texttt{nemotron-3-super}, a 120B-parameter mixture-of-experts model with 12B active parameters) served by Ollama Cloud through its OpenAI-compatible API, driven by DeepSeek Harness \texttt{\DshVersion} in headless mode with file, shell, web and sub-agent tools disabled, so the only tools are the harness's literature and record tools. Literature comes from arXiv, OpenAlex, Semantic Scholar and Crossref through a response cache shared by all runs, so that systems compared on an item see identical API responses whenever they issue identical queries. Semantic Scholar was used without an API key and rate-limited many requests; failed source calls are recorded and the search proceeds with the other sources, for all systems alike.

\paragraph{Systems.} \textsc{full}: the adaptive controller with self-challenge and critique revision. \textsc{nochal}: identical, with self-challenge off (the controller raises no challenge questions, so critique revision also never triggers). \textsc{pipe}: the fixed pipeline (coverage tier, one critique, refine, plan, finalise). All share the same hard caps: \MaxIterations{} agent turns, \MaxToolCalls{} tool calls, \MaxSearches{} searches, \MaxPapers{} papers, six papers read in depth, and 60 minutes per run (20 minutes per turn).

\paragraph{Model choice.} The study was planned with DeepSeek-V4.1-Flash. Measured on the calibration run below, a DeepSeek run cost about \$0.5--1.1 and the account served one request at a time, which put the pilot at roughly a day of compute. We therefore switched to the cheapest model on the account that passed our tool-calling checks: Nemotron~3 Super called both test tools with exactly correct nested arguments, whereas \texttt{gpt-oss:120b} altered a paper identifier and called the wrong tool, and its per-token price for this cache-dominated workload is roughly half DeepSeek's. Five DeepSeek pilot runs that had started were stopped before completion and are excluded.

\paragraph{Calibration.} One run with DeepSeek-V4.1-Flash (\textsc{full}, \textsc{scooped}, item 2609.11572) was made before the pilot to set budgets; it is excluded from all analyses. In 26 turns (30 minutes) it retrieved 100 papers but not the realising paper, which is retrievable by its title through arXiv and OpenAlex, and its critique nonetheless recorded substantial overlap with earlier work; its last 15 turns produced repeated experiment plans. The first observation is why verdict-only detection is secondary and verdict discrimination and realising-paper evidence are primary; the second is why turns are capped. The first Nemotron run, under an initial 45-minute cap, ended after 9 turns without its self-challenge ever running; before any further run we therefore made the \textsc{full} controller challenge the first critique immediately after recording it (\textsc{nochal} proceeds as before), and set the caps below. That run and one unfinished run are excluded.

\paragraph{Runs and statistics.} Each item is run under both conditions with each system, once (the model is sampled at the provider's default temperature, so a run is one draw). Comparisons are paired by item. For binary outcomes we report rates with Wilson 95\% intervals and exact McNemar tests on discordant pairs; for costs, medians and paired bootstrap 95\% intervals of the mean difference (10{,}000 resamples). With \PilotItems{} items the study is powered only for large effects; we treat it as a pilot and report effect sizes with their uncertainty rather than significance alone.
